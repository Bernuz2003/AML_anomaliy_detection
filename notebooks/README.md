# Notebooks

The repository keeps two Colab notebooks:

- `AM01_official_experiments_colab.ipynb`: official report-oriented execution notebook.
- `AM01_appendix_extended_ablation_colab.ipynb`: optional supporting analyses, currently multi-seed stability and artifact inspection.

The official notebook produces:

```text
MyDrive/AM01/results/official/
├── config/
├── tables/
├── figures/
├── extended_scores/
├── runs/
└── summary.md
```

The appendix notebook writes under:

```text
MyDrive/AM01/results/official/appendix/
```
